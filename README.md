## 🚀 Featured Projects

### 🌌 N-Body Gravitational Simulation — C# · Numerical Methods · Unity

A work-in-progress space simulation built around a **standalone physics engine** and a separate **Unity application** for visualization and further development.

- Implemented **Euler, fourth-order Runge–Kutta (RK4), and Velocity Verlet** integration methods.
- Designed the simulation engine to be independent of Unity's runtime and rendering components.
- Built benchmarks to compare numerical behavior across integration methods and time steps, including **energy conservation, convergence, and accuracy**.
- Developing a Unity-based environment to explore and visualize gravitational systems.

**Repositories:** [Physics Engine](https://github.com/irdof321/space-simulation-engine) · [Unity Application](https://github.com/irdof321/Space-simulation)

### 🤖 Pokémon Battle Automation & AI Agents — Python · Reinforcement Learning · LLMs

A modular framework for automating Pokémon battles by reading **Game Boy emulator RAM directly**, rather than relying on screen recognition.

- Reconstructs battle state from emulator memory using a layered approach to data access and interpretation.
- Uses a structured command and battle-control pipeline to execute actions.
- Includes a **reinforcement learning** workflow with **MaskablePPO**, custom rewards, randomized battle generation, and targeted test scenarios.
- Includes a separate **LLM-based battle decision agent**, using **Gemma 3 via Ollama** and **MQTT** to exchange structured battle states and actions.
- Validates LLM-selected moves and provides retry handling and a rule-based fallback.

**Repository:** [pokemon-yellow-bot](https://github.com/irdof321/pokemon-yellow-bot)

### 🗂️ CardBoard — Full-Stack Project Management Application

**Django · Django REST Framework · Keycloak/OIDC · Docker · React Router**

A Trello-inspired application organized around boards, columns, and cards.

- Backend APIs built with **Django REST Framework**.
- Authentication handled by **Keycloak / OpenID Connect**, with role-based access permissions.
- Containerized, multi-service development environment using **Docker Compose**.
- Server-rendered frontend built with **Remix / React Router v7**.

**Repositories:** [Backend & Infrastructure](https://github.com/irdof321/trello-like-app) · [Frontend](https://github.com/irdof321/cardboard-frontend)

### 📋 Log Manager — C++ · ROS · OpenCV · PostgreSQL
