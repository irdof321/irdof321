## 🚀 Featured Projects

### 🔗 **Highlighted Work**

- **[Pokémon Battle-Automation Framework + RL Agent (Python, PyBoy, Stable-Baselines3)](https://github.com/irdof321/pokemon-yellow-bot)**
  ✨ A framework that reconstructs full Pokémon battle state directly from Game Boy emulator RAM (no pixel/OCR guessing), driving an explicit, testable command-queue battle loop. On top of it: a from-scratch reinforcement learning pipeline (MaskablePPO) — custom reward shaping, a randomized-battle generator for unlimited training data, and hand-crafted test scenarios to validate specific tactical decisions.

- **[CardBoard — Trello-like Project Management App (Django, DRF, Keycloak/OIDC, Docker, Remix/React Router)](https://github.com/irdof321/trello-like-app)**
  ✨ Full-stack board/column/card app with authentication delegated to Keycloak (OIDC) instead of homemade auth, role-based permissions (superuser / staff-owner / member), and a 6-service Docker Compose stack. Frontend built with Remix / React Router v7 (SSR): [cardboard-frontend](https://github.com/irdof321/cardboard-frontend).

- **[Log Manager (C++, ROS, OpenCV, PostgreSQL)](https://github.com/irdof321/logger-irdof)**
  ✨ A scalable event logging system for any application. Associates events with logs, videos, text, and ROS topics.
